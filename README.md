# Clinic Document Management System

A scalable microservices-based system for managing clinic documents.

## 🚀 Tech Stack
- Java, Spring Boot
- Apache Kafka (event-driven communication)
- Eureka (service discovery)
- API Gateway
- Docker & Docker Compose
- AWS S3 (file storage)

## 🧩 Architecture
Frontend → API Gateway → Microservices → Kafka → Consumers

## 📦 Services
- Eureka Server
- API Gateway
- Document Service
- Notification Service
- Audit Service
- Frontend (React)

## ▶️ Run Locally
docker-compose up -d
